## Key Design Changes (Revision-0 → Revision-1)

1. **Authority = Projection** (not Event, not Domain State) — derived from ValidationEvent chain
2. **ValidationEvent = Authority Grant Event** — immutable fact, not Authority itself
3. **Human Review = Option B** — produces ValidationEvent via unified mechanism
4. **Identity Tuple** = (source_version_id, candidate_id, run_id, claim_id) — all MUST
5. **Two-layer enforcement** — IR Boundary (evidence chain) + Admission Boundary (candidate identity), proven independent
6. **AuthoritySnapshot** — IR generation freezes Authority state; Admission re-checks current state
